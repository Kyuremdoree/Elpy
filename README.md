# Elpy

## The project
Our project, **Elpy** (which takes its name from the word 'help' meaning 'to help users'), will be a toolbox containing at least 5 'tools', if you can call them that. For the moment, we're planning to make 1-2 of them each, but perhaps there will be extras depending on the individual and collective development of the project. 
The list, which is aimed more at students, currently consists of a tool for storing different google maps addresses with the possibility of adding events such as an appointment at the town hall with a date, time and geolocation. We also have plans for an MP4 to MP3 converter, a note-taking application for more efficient note-taking, a concentration study timer, and a currency converter.

In short, our tools could help anyone in their everyday life, and we intend to work hard to provide the best version of this application.

## The detailed tools
### Points of interest
Users will be able to place *points of interest* in places they want to remember, simply by clicking on the map where they wish to do so. These points will have a name and a list of events (such as appointments). Points associated with events will have a different colour to distinguish them from others, and a notification will be sent the day before the event as a reminder.

### Video to audio file converter. 
Users can select a video file (mp4 for example) from their phone's storage and save a version containing only the audio (in mp3 format).

### Note-taking
This tool allows users to create notes. Each note will have a title and content.

### Focus Timer
This tool is used to manage the distribution of time over a work session. Users can define the duration of their session, as well as the length and frequency of their breaks. The tool will then display a message on the screen with a sound to tell the user to take a break or resume work.

### Currency converter
This tool will convert Canadian dollars into euros and vice versa, retrieving the exchange rate in real time. There are two fields, one for each currency. By entering a price in one of the fields, its conversion is displayed in the other field.
